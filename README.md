# VisualResourceLinkerForSiv3D

Siv3D のリソース埋め込みを補助し、`Resource.rc` を GUI で編集するツール。

## 使い方

File > Open（Ctrl+O）で `Resource.rc` を開く。読み込んだリソースは Required / Optional / Custom の 3 つのタブに分かれて並ぶ。操作は行単位。

各行のチェックボックスで有効と無効を切り替える。無効にした行は `//` でコメントアウトされる。Erase ボタンを押すと、その行を削除できる。削除には制限がある。

Required のリソースは Siv3D 本体が要求するため、削除できない。

リソースの追加には Regist ボタンか、ウィンドウへのドラッグ＆ドロップを使う。ドロップしたファイルは Custom タブに追加される。パスはプロジェクトフォルダからの相対パスへ自動で変換される。変換は自動だ。

File > Save（Ctrl+S）で変更を書き戻す。File > Revert（Ctrl+R）を選ぶと、最後に読み込んだ時点まで変更がすべて巻き戻る。

## バックアップ

ファイルを開いた時点で、自動的にバックアップを作成する。保存先は元のファイルと同じフォルダ。

```
Resource.rc.2025-08-21_13-35-00.bak
```

復元は手作業で行う。現在の `Resource.rc` を削除するか、別名に変更して退避する。続いて、復元する `.bak` の名前を `Resource.rc` に変更する。それだけ。
